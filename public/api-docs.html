REST API Documentation

Supple Tracker exposes a JSON REST API for programmatic access. Use it to integrate with Apple Shortcuts, RFID tags, Home Assistant, or any HTTP client.

Base URL

Supplements

GET /api/supplements
List all supplements +

Returns all configured supplements ordered by sort order.

Response

[
  {
    "id": 1,
    "name": "Vitamin D",
    "default_dosage": "5000 IU",
    "button_color": "#ff6b35",
    "sort_order": 1,
    "created_at": "2026-01-15T10:00:00.000Z"
  }
]
POST /api/supplements
Create a supplement +

Creates a new supplement. It will appear as a button on the home screen.

Request Body

FieldTypeRequiredDescription
namestringYesSupplement name
default_dosagestringNoDefault dosage (e.g. "500mg")
button_colorstringNoHex color code (default: #6c757d)

Example

curl -X POST /api/supplements \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Vitamin D",
    "default_dosage": "5000 IU",
    "button_color": "#ff6b35"
  }'

Response

{
  "id": 1,
  "name": "Vitamin D",
  "default_dosage": "5000 IU",
  "button_color": "#ff6b35",
  "sort_order": 1
}
PUT /api/supplements/:id
Update a supplement +

Updates an existing supplement's name, dosage, color, or sort order.

URL Parameters

ParamDescription
idSupplement ID

Request Body

FieldTypeRequiredDescription
namestringYesSupplement name
default_dosagestringNoDefault dosage
button_colorstringNoHex color code
sort_orderintegerNoDisplay order

Example

curl -X PUT /api/supplements/1 \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Vitamin D3",
    "default_dosage": "10000 IU",
    "button_color": "#ff6b35",
    "sort_order": 1
  }'
DELETE /api/supplements/:id
Delete a supplement +

Deletes a supplement and all its associated log entries (cascade delete).

URL Parameters

ParamDescription
idSupplement ID

Example

curl -X DELETE /api/supplements/1

Response

{ "message": "Supplement deleted" }

Logging

POST /api/log
Log a supplement intake +

Records that a supplement was taken. This is the primary endpoint for integrations (Apple Shortcuts, RFID tags, etc.).

Request Body

FieldTypeRequiredDescription
supplement_idintegerYesID of the supplement (from GET /api/supplements)
dosagestringYesDosage taken (e.g. "500mg", "2 pills")
taken_atstringNoISO 8601 timestamp (defaults to now)
notesstringNoOptional notes (e.g. "with food")

Example

curl -X POST /api/log \
  -H "Content-Type: application/json" \
  -d '{
    "supplement_id": 1,
    "dosage": "5000 IU",
    "notes": "with breakfast"
  }'

Response

{
  "id": 42,
  "supplement_id": 1,
  "supplement_name": "Vitamin D",
  "taken_at": "2026-02-20T14:30:00.000Z",
  "dosage": "5000 IU",
  "notes": "with breakfast"
}

Errors

StatusCause
400Missing supplement_id or dosage
404Supplement ID does not exist

Export

GET /api/export/csv
Export logs as CSV +

Downloads all log entries as a CSV file. Columns: Supplement, Taken At, Dosage, Notes.

Example

curl -O /api/export/csv

Returns Content-Type: text/csv with filename supplement-logs.csv.

GET /api/export/json
Export logs as JSON +

Downloads all log entries as a JSON file with full details including IDs and timestamps.

Example

curl -O /api/export/json

Returns Content-Type: application/json with filename supplement-logs.json.

Error Responses

All errors return JSON with an error field and sometimes a message field with more detail.

StatusMeaning
400Bad request - missing or invalid parameters
404Resource not found
500Internal server error

Example Error

{
  "error": "Supplement not found",
  "message": "No supplement exists with id 99. Create it in Settings first or check GET /api/supplements for valid IDs."
}
